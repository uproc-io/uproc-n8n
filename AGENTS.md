## Authentication

The credential type `UProcApi` uses **Basic Auth** with email + API key.

- **email** → Your UProc email (username field)
- **api_key** → Your real API key (from Settings → Integrations at app.uproc.io)

## Node modules

### UProc Node

The main n8n node exposes UProc's data process capabilities.

**Supported operations:**
- All 11 categories (audio, communication, company, finance, geographic, image, internet, personal, product, security, text)
- Dynamic tool selection via `/process` endpoint
- Error handling with `continueOnFail` support

**Parameters:**
- `group` → Category group
- `tool` → Specific tool within the group
- Tool-specific parameters (dynamic based on selected tool)

## Creating a PR to n8n-io/n8n

The script `create-n8n-pr.sh` automates creating a PR to the official n8n repository:

```bash
./create-n8n-pr.sh
```

This script:
1. Clones/updates a fork of n8n-io/n8n
2. Syncs from upstream (latest official n8n code)
3. Copies the UProc node to the correct location
4. Creates a PR to `n8n-io/n8n/main`

## Notes

- The node uses the declarative/low-code style (recommended by n8n)
- Credentials are loaded via `ICredentialType` with Basic Auth
- The node supports batch processing (multiple items)
- Error handling uses `continueOnFail` for graceful failures
- The node follows n8n's naming conventions and guidelines
